# 1.4.2 性能说明

[返回 README](../README.md)

1.4.2 的优化集中于减少重复工作：未变列表不重绘、时间格式化器复用、空闲轮询降频、诊断和直播摘要减小、相同会话跳过重复写盘、成功请求明细仅在调试时输出。错误、风控和手动通知日志保留；通知发送前仍先保存记录。

| 模拟对照项目 | 1.4.1 | 1.4.2 |
| --- | ---: | ---: |
| 空闲直播页 60 秒轮询请求数 | 12 | 4 |
| 相同数据刷新 20 次，两张直播列表重建次数 | 40 | 0 |
| 20 次相同会话保存的写盘次数 | 20 | 1 |
| 直播快照 JSON 大小 | 136,695 字节 | 15,646 字节 |

使用 Node VM、模拟 DOM 和时钟，20 位主播、100 条模拟通知，每条正文 400 字符。快照大小不含响应外层与风控信息。原始结果见 [performance-results.json](performance-results.json)，复现方法见[开发文档](development.md)。

这些是操作次数和数据量，不代表真实服务器 CPU、内存、浏览器帧率或网速。实际记录少、正文短时，流量节省比例也会不同。
