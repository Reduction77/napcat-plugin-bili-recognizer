# 自备贴纸目录

把 PNG / JPG / WEBP / SVG 图片直接放进这个目录，直播卡片会自动叠加。

文件名前缀决定贴在哪里（区分大小写不敏感）：

| 前缀 | 位置 | 建议尺寸 |
| --- | --- | --- |
| `top-` | 卡片顶部装饰带，最多叠 3 个 | 宽 120–240px，透明底 PNG |
| `tag-` | 主播名字右边的徽章 | 48×48 左右 |
| `corner-` | 卡片右下角 | 宽 160–240px |

示例：`top-星星.png`、`tag-适格者.png`、`corner-爱弥斯.png`

限制：

- 单个文件不超过 2MB，整个目录合计不超过 10MB，超出会被跳过并在 WebUI 提示。
- 文件名前缀不符合规则的文件会被忽略（例如 `爱弥斯.png` 不生效，`corner-爱弥斯.png` 才生效）。
- 建议用透明背景 PNG；白色底会在卡片上留下方块。
- 贴纸由你自己提供与维护。角色立绘、表情包等素材的版权请自行确认。
